# Changelog

This file records the reviewed source snapshot and documentation additions. Historical release dates and version milestones were not available; no release history is inferred from package versions.

## Unreleased — documented baseline

### Existing functionality

- React landing page, authentication interface and view navigation.
- Express/MySQL registration and login with bcrypt; password-change API.
- Lead CRUD, search, filtering, sorting, pagination and bulk deletion interface.
- Admin, Sales and Staff UI permissions.
- Dashboard statistics and recent activity logging.
- Profile, settings and help interfaces with partially simulated functionality.

### Documentation additions

- Detailed README with local setup, API reference and inferred database schema.
- Architecture and project structure guides.
- Contribution guidelines and safe configuration template.

### Known limitations / planned improvements

- Server-side authentication and authorization, secret management and safe login responses.
- Persistent profile/settings, real CSV export and team management.
- Persist additional lead fields or remove unsupported form fields.
- Improve error handling, audit identity and automated tests.

No application code changes are included in this documentation package.
